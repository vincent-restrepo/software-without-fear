# software-without-fear

Repositorio de práctica del taller «Software sin miedo»: aquí se monta una página web desde cero y se le va sumando lo que hace robusto a un proyecto de software (ramas, pull requests, chequeos automáticos y despliegue).

## Reglas del taller
- Nada se escribe directo en `main`: cada cambio va en una rama y se une con un pull request.
- Se empieza con una página fea y simple; se mejora por capas.
- Quien trabaja con una IA le pega primero el bloque de contexto de la guía.
